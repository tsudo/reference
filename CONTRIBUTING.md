# Contributing

Corrections and additions are welcome — broken source links, outdated document versions, and new sources within the existing bucket taxonomy.

## Suggesting a Correction or Addition

- **Broken/stale link, outdated version:** open an issue or PR updating the row in [CATALOG.csv](CATALOG.csv) and, if applicable, [scripts/sources.yaml](scripts/sources.yaml).
- **New source:** open an issue first — confirm it fits an existing `content_type` bucket (see [README.md](README.md#machine-readable-access)) before adding it.
- **PRs:** add or update the `CATALOG.csv` row, place `format=MD/PDF/XLSX` files at the matching `doc_path`, and update the relevant bucket's `README.md` if scope changes.

## What This Repo Is Not

Not a place for opinion pieces, vendor marketing, or content outside cybersecurity/GRC reference material. Original analysis belongs elsewhere — this is a curated pointer/archive library.
